# Seraphim Macro v1.0.3 — License Integration

Your macro zip (`Seraphim-Sharing/Seraphim-Macro-v1.0.3.zip`) is not in the GitHub repo, so the cloud agent cannot open it directly. Use one of the options below.

## Option A — Easiest for the agent (recommended)

Upload the zip to GitHub so it can be downloaded and patched automatically:

1. Open: https://github.com/corbintalbert9744-art/Seraphim-Services/releases/new
2. Tag: `macro-v1.0.3`
3. Title: `Seraphim Macro v1.0.3 (source)`
4. Attach: `Seraphim-Macro-v1.0.3.zip`
5. Publish the release
6. Tell the agent: "macro zip is uploaded"

The agent can then extract it, patch `main.js`, and rebuild if needed.

## Option B — Patch on your PC (no upload)

1. Unzip `Seraphim-Macro-v1.0.3.zip` from your `Seraphim-Sharing` folder
2. Open Command Prompt in this repo folder
3. Run:

```bat
tools\macro-app\PATCH-MACRO.bat "C:\full\path\to\extracted\Seraphim-Macro-v1.0.3"
```

This copies `license.mjs` + `license-check.mjs` next to `main.js` and attempts to wire validation in.

## Option B2 — Manual copy (if patch script misses your main.js layout)

Copy these two files into the same folder as `main.js`:

- `tools/macro-app/license.mjs`
- `tools/macro-app/license-check.mjs`

Add to `main.js`:

```javascript
import { validateLicenseKey } from "./license-check.mjs";

const result = validateLicenseKey(userEnteredKey);
if (!result.valid) {
  dialog.showErrorBox("Invalid License", result.reason);
  app.quit();
}
```

## Keys that work

Only keys generated by **Seraphim Keyboard Macro v1.2.0** (signed `SRPH-` format):

https://github.com/corbintalbert9744-art/Seraphim-Services/releases/download/keyboard-macro-v1.2.0/Seraphim-Keyboard-Macro.exe

Older admin-panel keys will **not** validate.

## If you only can share a small file

Paste the **license / activation section** of `main.js` (roughly 30–80 lines around where the user enters their key). That is enough to wire validation without the full zip.
